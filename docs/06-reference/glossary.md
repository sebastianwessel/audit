# Glossary

| Term | Meaning |
| --- | --- |
| Attack vector | A bounded security question the audit will investigate. |
| Evidence | A relative source location and bounded excerpt supporting a conclusion. |
| Plan | The human-reviewable list of vectors and their scope. |
| Finding | A candidate weakness grounded in evidence. |
| Coverage | The record of which planned vectors completed. |
| Candidate | A result requiring human validation; not a confirmed vulnerability. |
| Path jail | The rule that confines reads to an approved root. |
| Context file | An explicitly selected project document used to improve focus. |
| Data-protection review | Review of code paths that may expose PII, secrets, credentials, tenant data, logs, or proprietary information. |
| Static review | Analysis of repository content without running or probing the application. |
