# Specification migrations

Record material change notes here. A note is required when a persisted plan,
finding, report, or run artifact changes meaning, requiredness, enum values,
approval semantics, or path rules. It is also required for a material security
or evaluation-protocol change that affects admission, coverage, checkpoint
reuse, or diagnostic interpretation.

These notes explain a breaking evolution; they never authorize a legacy reader,
translation layer, migration code, or compatibility fallback. The current strict
schema and source specification remain the only accepted contract.
