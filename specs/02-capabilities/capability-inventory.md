## Evaluation end-to-end chain

`evaluation` is a contributor/CI capability, not a target-facing audit command. A run validates a benchmark pack, creates a run manifest, executes the normal plan/audit/report path against isolated fixture roots, scores only from trusted answer keys, writes JSON plus Markdown metrics, and returns a gate result. A malformed pack, missing answer key, answer-key exposure, or incomplete score is a failed evaluation rather than a passing zero.

## Security review focus

Every applicable plan includes a data-protection review dimension. It asks whether the repository or its interfaces can expose PII, credentials, secrets, personal data, tenant data, logs, telemetry, or proprietary material; whether access controls and retention boundaries are present; and whether error/reporting paths leak sensitive values. The tool reports evidence and proposed improvements without collecting live data or attempting exfiltration.
