# Evidence-first review pipeline

Status: superseded in detail by `07-hypothesis-discovery-and-grounding.md`; this document retains the shared evidence and recovery boundary.

The language-neutral static audit flow is:

```text
approved vector → evidence map → candidate-blind source posture
  → hypothesis discovery → candidate grounding → canonical admission
  → verifier → synthesis → report
```

Evidence mapping owns neutral, source-backed facts, controls, one explicit control-fact inventory for every approved review obligation, unanswered obligations, and limitations. The inventory must exactly list the map facts labelled `control` for its obligation; it is provenance coverage, not a claim that a control exists or works. Source posture owns one candidate-blind conclusion for every approved review obligation and must cite every such mapped control for that obligation. Discovery owns non-reportable seeds and obligation closures. Grounding owns the one-to-one conversion of a valid seed into either `null` or a complete candidate. Admission and verification own structural source integrity and static falsification respectively. No phase infers security meaning deterministically.

All model stages receive only the approved vector scope, complete read-only source tools, and applicable advisory context. The target is never executed; there are no network, shell, write, edit, or live-target tools. Unknown-language regular UTF-8 source remains valid evidence. A normal stage starts unsplit. Only a normalized provider context-window overflow can trigger stable source-path/source-range/applicable-context partition recovery; it may never silently omit a file, range, context body, match, or tool response.

Discovery seeds are deliberately ephemeral: they are not persisted, reportable, or reusable. A canonical grounded candidate draft is written only after seed provenance, exact grounding identity, map/posture references, closure declarations, and ordinary candidate integrity validation pass. It contains only redacted canonical candidates, closures, and source-free stage observations. On resume, only exact-binding evidence-map, source-posture, candidate-grounding, and terminal-result artifacts may be reused. Older investigation and candidate-repair artifacts are rejected by shape and are never read from their historical paths.

Before source posture starts, every approved review obligation must be explicitly covered by at least one validated neutral map fact or be listed as unanswered, but never both. Its explicit control inventory must exactly reconcile to the retained neutral `control` facts. This is a completeness and recovery boundary, not a conclusion about the code: an unanswered obligation or mismatched control inventory produces visible incomplete coverage rather than a clean result or a deterministic finding.

The source-free closure matrix is the single persisted account of those phase states. The contract rejects a mismatched repeated obligation identity, a map state/count contradiction, an applicability reason outside a not-applicable posture, or a terminal disposition that conflicts with retained candidate or admitted-finding counts. Vector and report aggregates are derived-conserved views of that matrix and their owned finding queues; no consumer may accept an artifact whose counters cannot reconcile to those canonical children.


The source-free diagnostic ledgers must remain closed:

- discovery seeds = grounding nulls + binding rejections + submitted candidates;
- submitted candidates = admission and verifier terminal outcomes;
- reconciled verifier outcomes = post-verification rejections + admitted findings.

No-candidate is a bounded model conclusion, never a deterministic assertion that the code is safe. Incomplete or not-reached obligation closure prevents completed coverage.
