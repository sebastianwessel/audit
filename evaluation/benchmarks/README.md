# Benchmark packs

A benchmark pack names its fixture roots, case ids, taxonomy version, answer-key digest, provenance records, and scoring thresholds. Pack versions are immutable after publication; a changed fixture creates a new version.

`../candidates/` is earlier in the lifecycle: it stores metadata-only acquisition leads, never fixtures, target source, expected labels, or answer keys. A candidate registry is not a benchmark pack and has no scoring or readiness effect.
