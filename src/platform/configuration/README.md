# Configuration adapter

Loads the optional project-local `.env` and inherited environment, then validates the closed runtime configuration. `RuntimeConfigurationDefaults` is the sole owner of the default OpenAI / `gpt-5.6-terra` route, artifact roots, evaluator roots, same-route verification mode, and positive in-flight queue capacity. Precedence is built-in defaults, inherited environment, then `.env`; CLI inputs select an operation but never override configuration. It owns optional provider/model overrides, separate `AUDIT_PUBLIC_ARTIFACT_DIR` and `AUDIT_PRIVATE_WORK_DIR` roots, evaluation paths, and `AUDIT_MAX_PARALLEL_VECTORS`; the queue never caps total review work. Credentials never leave this boundary except through the provider adapter.
